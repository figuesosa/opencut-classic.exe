Unzip and run opencut-classic.exe. You need Chrome, Brave, Chromium, or Edge.

This is a local Windows package of OpenCut Classic. We did not develop OpenCut.
Original: https://github.com/opencut-app/opencut-classic
Current rewrite: https://github.com/opencut-app/opencut

The Sounds catalog and the feedback button are left out. Editing runs on this computer.
