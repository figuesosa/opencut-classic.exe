# OpenCut for Windows

Desktop package for [OpenCut Classic](https://github.com/opencut-app/opencut-classic).

The download is a zip. Unzip it and run `OpenCut.exe`. The editor opens in its own window, and projects stay on that computer.

Releases are built by GitHub Actions from the public OpenCut Classic source. Sound search and account features still need their own API keys; the timeline, preview, and local projects do not.
